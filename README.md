# Zhou Lab — VHH Library Selection NGS Data Summary

Analysis code and derived data summaries for deep-sequenced VHH (single-domain antibody /
nanobody) libraries from phage, yeast, viral and mammalian selections.

Associated manuscript:

> **Harnessing Endocytosis with Viral Display to Select Highly Developable,
> Internalizing Antibodies for Precision Therapy and Delivery**

This module translates collapsed NGS reads of a fixed-scaffold VHH library into protein,
annotates the framework (FR1–FR4) and complementarity-determining regions (CDR1–CDR3),
applies quality filters, and collapses variants by CDR amino-acid content to summarize
clonal diversity per selection sample.

---

## What it does

Each sequencing sample is a **collapsed** read table (`nt,count`: unique nucleotide sequence +
read count). The VHH sequences share a constant framework scaffold; only the CDR loops are
diversified. For every `*.collapsed.csv` in a folder the pipeline:

1. **Translates** each nucleotide sequence to protein (reading frame 0).
2. **Segments** it into `FR1, CDR1, FR2, CDR2, FR3, CDR3, FR4` by locating six conserved
   framework "anchor" motifs (fuzzy Hamming search) and carving the CDRs between them —
   robust to framework point-mutations *and* variable CDR length.
3. **Filters** reads, dropping those that contain `N`, contain a premature stop codon (`*`),
   or are low quality (an anchor cannot be located, or inter-anchor spacing is not in-frame =
   frameshift).
4. Writes a per-sample filtered, annotated table (`*.translated_filtered.csv`).
5. **Collapses** the filtered reads by CDR amino-acid content (CDR1+CDR2+CDR3), summing
   counts across all synonymous / framework-variant nucleotide sequences
   (`*.cdr_collapsed.csv`).
6. Writes an aggregate `QC_summary.csv`.

No third-party libraries are required — the genetic code is implemented directly, so the
script runs on a bare Python 3 interpreter.

## Quick start

Requires only Python ≥ 3.6.

```bash
# reproduce the bundled demo
python src/process_vhh_ngs.py examples
#   -> examples/demo.translated_filtered.csv, examples/demo.cdr_collapsed.csv, examples/QC_summary.csv

# run on your own folder of *.collapsed.csv files
python src/process_vhh_ngs.py "/path/to/NGS_run_folder"
```

Every `*.collapsed.csv` in the target folder is processed; outputs are written next to the inputs.

## Input / output format

**Input** `*.collapsed.csv`
| column | meaning |
|---|---|
| `nt`    | unique nucleotide sequence (a VHH variable-region amplicon) |
| `count` | number of reads collapsed into that sequence |

**Output 1** `<sample>.translated_filtered.csv` — one row per passing nucleotide sequence:
`nt, count, VHH_seq, FR1, CDR1, FR2, CDR2, FR3, CDR3, FR4`

**Output 2** `<sample>.cdr_collapsed.csv` — one row per unique CDR combination, sorted by count:
`CDR1, CDR2, CDR3, count, n_nt_variants, VHH_seq_example`
(`n_nt_variants` = how many distinct nucleotide sequences were merged into that CDR clone.)

**Output 3** `QC_summary.csv` — one row per sample:
`sample, in_unique, in_reads, kept_unique, kept_reads, cdr_unique, drop_N, drop_stop, drop_lowqual`

## Method details

**Reference scaffold** (116 aa; constant framework, diversified CDRs):

```
EVQLVESGGGLVQPGGSLRLSCAASGYTFTENTMHWFRQAPGKEREWVASIYSSSSYTYYADSVKGRFTISRDNSKNTAYLQMNSLRAEDTAVYYCARAYYGFDYWGQGTLVTVSS
```

**Region boundaries** (residue numbers within the reference):

| Region | Residues | Reference sequence |
|---|---|---|
| FR1  | 1–26    | EVQLVESGGGLVQPGGSLRLSCAASG |
| CDR1 | 27–35   | YTFTENTMH |
| FR2  | 36–49   | WFRQAPGKEREWVA |
| CDR2 | 50–59   | SIYSSSSYTY |
| FR3  | 60–98   | YADSVKG … VYYCAR |
| CDR3 | 99–105  | AYYGFDY *(variable length)* |
| FR4  | 106–116 | WGQGTLVTVSS |

Notes:
- Amplicon reads begin *inside* FR1, so the `FR1` field contains only its C-terminal portion
  (`…SLSCAASG`), and reads are frequently truncated mid-codon at the 3′ end (`FR4` = `…WGQGTL`).
  This reflects read coverage, not a defect.
- `CDR1` is annotated as residues 27–35 (`YTFTENTMH`); positions 27–30 (`YTFT`) are diversified
  in this library, so they are included in CDR1 rather than the framework.
- To adapt to a **different scaffold**, edit `REF_NT`, `REF_AA`, and the six `ANCHORS`
  (name, motif, reference offset) at the top of `src/process_vhh_ngs.py`. The script asserts
  that `REF_NT` translates back to `REF_AA` at startup, so a mis-edit fails immediately.

## Raw data / reproduction

Raw sequencing reads and the per-sample collapsed tables are not committed to this repository.
Deposit the raw reads in a sequence archive (e.g. NCBI SRA / EBI ENA) and point to the
accession here on publication. Given the collapsed tables, `src/process_vhh_ngs.py` regenerates
all filtered, annotated, and CDR-collapsed outputs and the `QC_summary.csv` deterministically.
